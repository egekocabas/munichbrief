# Contributing to MunichBrief

External code contributions and pull requests are not accepted. Development is
maintainer-led; automated Dependabot updates are allowed.

Reproducible [bug reports](https://github.com/egekocabas/munichbrief/issues/new?template=bug_report.yml)
and private [security vulnerability reports](SECURITY.md) are welcome. For
operational incidents or corrections to generated content, use the
[contact page](https://munichbrief.de/en/contact).

Do not include credentials, databases, real police article copies, generated
model output, personal information, or private deployment details in reports.
Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

PR titles must use Conventional Commits, for example
`fix(parser): handle standalone release headings`.
